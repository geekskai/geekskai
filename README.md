## About Me

I build and operate practical web products with a focus on clear user workflows, reliable backend boundaries, and search-friendly content.

My current work includes:

- Building **GeeksKai Tools**, a multilingual collection of focused browser utilities.
- Developing **Geekskai Audio Toolkit**, a local-first workspace for private batch audio preparation.
- Improving SoundCloud workflows, quotas, provider integrations, and format transparency.
- Designing SEO systems that connect content, metadata, structured data, screenshots, and real product behavior.
- Exploring product opportunities around developer tools, media workflows, document processing, and creator utilities.

My main stack includes **TypeScript, React, Next.js, Tailwind CSS, Node.js, PostgreSQL-compatible systems, PayPal, Clerk, Neon, and Vitest**.

## Engineering Principles

- Start from the user's actual workflow.
- Keep product behavior, marketing copy, analytics, and SEO metadata aligned.
- Prefer reliable provider and server-side evidence over assumptions.
- Treat unknown demand, satisfaction, and business outcomes as unknown until measured.
- Build focused features, verify them locally, and keep production status explicit.
